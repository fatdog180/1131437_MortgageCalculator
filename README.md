# 個人房貸試算器 (Mortgage Calculator)

這是一個使用 C# Windows Forms 開發的房貸試算工具，採用「本息平均攤還法」進行計算。

## 功能特色
* 支援房屋總價與自備款 (比例/金額) 的自動換算防呆機制。
* 可設定貸款年限與寬限期。
* 清楚顯示每月應繳金額、首期本息以及總還款數據。
* 內建計算公式參考。
